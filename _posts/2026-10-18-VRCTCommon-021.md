- Fixed [`ArrayUtils.RemoveElement`]({{ site.baseurl }}/docs/common/utilities/#arrayutils) leaving the last slot of the
  returned array empty unless the last element was removed
- `ArrayUtils.RemoveElement` now returns the array unchanged when given a negative index instead of throwing an exception
- Fixed `ArrayUtils.FindElement` being unable to locate `null` elements
- `ArrayUtils.FindElement` now returns `-1` for negative or out of range offsets instead of throwing an exception
