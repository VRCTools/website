🐞 Fixed
- [`ArrayUtils.RemoveElement`]({{ site.baseurl }}/docs/common/utilities/#arrayutils): the last element of the returned array was left empty (`null` or the type's default value) unless the removed element was the last one
- `ArrayUtils.RemoveElement`: a negative index now returns the array unchanged instead of throwing an exception
- `ArrayUtils.FindElement`: searching for null now finds null elements; the fix in 0.2.0 was incomplete
- `ArrayUtils.FindElement`: a negative or out-of-range offset now returns `-1` instead of throwing an exception
