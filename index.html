why vrctools

No-code first

Every component is configured from the inspector. Prefabs cover the common cases so you can drag, drop and test.

Local, synced, persisted

Pick per-player, instance-wide or saved-across-visits state with the same building blocks.

Script friendly

Everything is a regular UdonSharp behaviour with events you can subscribe to from your own code.

Open source

Apache 2.0 licensed. Found a bug or a gap in these docs? Pull requests are welcome.
